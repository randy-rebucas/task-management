# Tech & Product Workflow

## Overview
This document describes the workflow for the Tech & Product role.

## Typical Workflow Stages
1. Requirement Gathering
2. Design & Development
3. Testing
4. Deployment & Maintenance

## Key Responsibilities
- Gather and analyze requirements
- Develop and test products
- Maintain and improve systems

## Example Transitions
- Gathering → Design
- Design → Testing
- Testing → Deployment
