# System Guide

This guide helps all team members understand how to navigate and use the task management platform effectively.

---

## Getting Started

### Logging In
1. Navigate to the login page.
2. Enter your registered email and password.
3. If you have forgotten your password, use the **Forgot Password** link.
4. Upon login, you will land on the **Dashboard**.

---

## Dashboard Overview

The dashboard provides a real-time snapshot of:
- **My Tasks** – Tasks assigned to you
- **Team Activity** – Recent activities across your team
- **KPIs** – Key performance metrics for your role
- **Notifications** – Alerts and updates relevant to you

---

## Core Modules

### Tasks
- Create, assign, and manage tasks
- Set due dates, priorities, and attachments
- Track task status through workflow stages
- Add comments and log time against tasks

### Workflow
- View available workflow statuses for tasks
- Transition tasks between stages as work progresses
- Some transitions may require remarks or approvals

### CRM
- Manage leads, clients, and deals
- Log interactions and track deal stages
- Follow up with clients and manage pipelines

### Reports & Analytics
- Generate reports on tasks, team performance, and KPIs
- Filter by date, department, or staff member
- Export data as needed

### Notifications
- Receive alerts for task assignments, status changes, deadlines, and approvals
- Manage notification preferences in Settings

### Field Monitoring
- Track field staff activities and sessions
- Log visits and submit proof of work
- Monitor field activity in real time

### Calendar
- View tasks and events in calendar format
- Plan and schedule upcoming work

### Performance
- Set and track performance targets
- Review individual and team KPIs

Access to modules and actions is determined by your assigned **role**. Contact your administrator if you need access to additional features.

## Tips for Daily Use
- Check the Dashboard and notifications every morning
- Update task statuses regularly to keep the team informed
- Use comments on tasks to document decisions and blockers
- Log time accurately for reporting and billing purposes
- Reach out to IT/Tech support for any technical issues

## Step-by-Step: Common Tasks

### Creating a Task
1. Go to **Tasks** in the sidebar
2. Click **+ New Task**
3. Fill in: Title, Description, Assignee, Due Date, Priority, Type
4. Attach files if needed
5. Click **Save**

### Transitioning a Task Status
1. Open the task
2. Click the **Status** dropdown or workflow transition button
3. Select the next status
4. Add remarks if required
5. Submit for approval if prompted

### Logging Time on a Task
1. Open the task
2. Click **Log Time**
3. Enter hours, date, and notes
4. Click **Save**

### Generating a Report
1. Go to **Reports** in the sidebar
2. Select the report type
3. Set the date range and filters
4. Click **Generate**
5. Export as PDF or CSV if needed

### Submitting Proof of Work (Field Staff)
1. Navigate to **Proof of Work**
2. Click **+ Submit Proof**
3. Upload photos and fill in task details
4. Click **Submit**

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Can't log in | Check credentials; use Forgot Password if needed |
| Page not loading | Refresh browser; clear cache; try incognito mode |
| Permission denied | Contact your admin to review your role |
| Notification not received | Check notification settings in **Settings > Notifications** |
| Can't transition a task | You may lack the required role or approval is needed |
| Report export failing | Try a smaller date range or contact Tech support |
| File upload failing | Check file size (max 10MB) and file type |
